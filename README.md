# 🤖 AI Chatbot (Java - If Else Based)

This is a simple AI chatbot developed using Java.  
The chatbot interacts with users and provides responses using basic **if-else logic**.

---

## 🚀 Features
- Console-based chatbot  
- Takes user input  
- Responds using predefined conditions  
- Simple and beginner-friendly logic  

---

## 🛠️ Tech Stack
- Language: Java  
- Concepts Used: If-Else Statements, String Handling, Loops  

---

## 📂 How It Works
1. User enters a message in the console  
2. Program checks input using if-else conditions  
3. Based on the condition, chatbot gives a response  

---

## 💡 Example
User: Hello  
Bot: Hi! How can I help you?

User: How are you?  
Bot: I'm fine! 😊
